# IPL Auction SQL Project

## About the Project
This project is based on IPL match and ball-by-ball data.
SQL is used to analyze IPL matches, teams, runs, boundaries, dot balls, dismissals, bowlers, and venues.

## SQL Concepts Used
- SELECT
- WHERE
- GROUP BY
- ORDER BY
- JOIN
- CASE WHEN
- COUNT()
- SUM()
- DISTINCT
- CREATE TABLE
- Date and Year Extraction

## Analysis Performed
- Count of cities that hosted IPL matches
- Boundary and dot-ball analysis
- Team-wise boundaries
- Team-wise dot balls
- Dismissal analysis
- Top 5 bowlers based on extra runs
- Venue-wise total runs
- Year-wise total runs at Eden Gardens

## Project File
- `IPL_Auction_Project.sql` – SQL queries used in the project.
